# backgammon-lite

简化版双陆棋（Backgammon），纯 Python 标准库实现，带贪心 AI 自动演示。

## 玩法

- 24 个点，白方从 24→1 走、黑方从 1→24 走，每方 15 子，标准开局布子
- 每回合掷两个骰子按点数走棋；掷出双骰可走 4 次
- 落到对方单子（blot）上则打中，对方子送上 bar；bar 上有子必须先入场
- 15 子全部进入本营（白方 1–6 点 / 黑方 19–24 点）后才能 bear off（收子）
- 收子可用精确点数；大点数时可从最高占子点收子
- 先收完 15 子者胜

## 用法

```bash
python3 -m backgammon_lite              # 人机交互（回合制文本）
python3 -m backgammon_lite --auto       # AI 对 AI 自动演示（默认 10 局）
python3 -m backgammon_lite --auto --games 50 --seed 7 --verbose
```

交互走棋格式：`起点-落点`，如 `13-10`、`bar-22`（入场）、`6-off`（收子）；`q` 退出。

## 设计取舍

- AI 是 1 步贪心（打子 > 收子 > 入场 > 叠子成锚 > 避免留单子），加两种骰序试走选优；不做深层搜索
- 开局固定白方/黑方轮流先手（`--auto` 按局数交替），人类对局的"掷骰定先后"未实现
- 400 回合上限防无限对局，撞上限判和棋

## 诚实局限

- **简化规则**：无加倍骰、无 Crawford 规则、无 Jacoby 规则；不是完整比赛规则
- AI 很弱：贪心策略不懂造点/封堵 timing，熟悉规则的人类通常能赢
- 文本回合制界面，无图形/动画/存档/悔棋；Python 3.10+，纯标准库
